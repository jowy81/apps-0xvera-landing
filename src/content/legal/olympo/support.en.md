# Olympo Support

Olympo is a **private** 0xVera platform. It is not available for public registration or download.

Authorized operators can contact **support@0xvera.com**.

## Please include

- That the request concerns Olympo
- A clear description of the issue
- Relevant timestamps (and timezone) when useful

## Do not send sensitive data

Do not send OAuth client secrets, refresh tokens, API keys, passwords, or unnecessary personal calendar contents unless explicitly requested for a controlled support case.
